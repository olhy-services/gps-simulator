# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, aceite críticas ao código (não à pessoa) e não
tolere assédio. Casos de violação podem ser reportados em privado pelo
[reporte de segurança do GitHub](https://github.com/olhy-services/gps-simulator/security/advisories/new)
ou para os mantenedores do repositório. Todo reporte é tratado com sigilo.
